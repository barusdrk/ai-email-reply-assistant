# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone participating in this project.

## Expected Behavior

Please:

- Be respectful.
- Be constructive.
- Welcome new contributors.
- Accept feedback professionally.
- Focus discussions on improving the project.

## Unacceptable Behavior

Examples include:

- Harassment
- Personal attacks
- Hate speech
- Discrimination
- Threats or intimidation
- Publishing private information without permission
- Deliberate disruption of discussions

## Enforcement

Project maintainers may remove comments, issues, pull requests, or other contributions that violate this Code of Conduct.

Repeated or severe violations may result in temporary or permanent removal from the project.

## Reporting

If you experience or witness unacceptable behavior, please contact the project maintainer privately through GitHub.

Reports will be handled respectfully and reviewed as promptly as practical.

## Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Project documentation
- Other project-related community spaces

Thank you for helping create a positive community.
