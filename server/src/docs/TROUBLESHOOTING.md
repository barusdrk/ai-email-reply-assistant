```md id="v4sxde"
# Troubleshooting

## MongoDB Connection Failed

Check

- MONGODB_URI
- Network access
- Database user credentials

---

## Redis Connection Failed

Check

- REDIS_URL
- Redis server
- Firewall

---

## JWT Invalid

Verify

- JWT_SECRET
- Authorization header
- Token expiration

---

## Gmail OAuth Error

Check

- Redirect URI
- Client ID
- Client Secret
- OAuth scopes

---

## Outlook OAuth Error

Verify

- Azure App Registration
- Redirect URI
- Microsoft Graph permissions

---

## OpenAI Error

Verify

- OPENAI_API_KEY
- API quota
- Selected model

---

## BullMQ Jobs Not Running

Check

- Redis
- Worker process
- Queue registration

---

## Socket.IO Not Connecting

Verify

- CLIENT_URL
- CORS configuration
- Authentication token

---

## Render Deployment

Verify

- Environment variables
- Build command
- Start command
- Node.js version
```
